# 家庭网页：我们的家

一个静态的家庭门户站点，用来汇总家庭成员、时间线、相册、任务和食谱等信息。页面使用原生 HTML、CSS 与 JavaScript 构建，可直接在任何静态服务器或本地浏览器打开。

## 功能概览

- **主页亮点卡片**：展示本周家庭活动亮点。
- **家庭时间线**：按时间顺序呈现近期事件，包含地点与标签。
- **成员卡片**：介绍家庭成员的角色、关注焦点和近期备注。
- **影像集相册**：以主题呈现照片，附带描述与日期。
- **家务与待办看板**：按照类别整理当前任务及负责人。
- **家庭食谱**：记录常用菜谱与标签，方便分类查找。
- **愿望表单与提示**：示例表单用于暂存愿望，并提供浮层提示。

## 使用方式

1. 将项目克隆或下载至本地。
2. 在浏览器中直接打开 `index.html` 即可体验页面。
3. 若需部署，可将整个仓库内容上传至任意静态托管服务（如 GitHub Pages、Vercel、Netlify 等）。

## 自定义数据

页面所有展示数据均存放于 `assets/main.js` 的 `data` 对象中，可按需修改或扩充。

- 新增时间线事件：在 `data.timeline` 数组中追加对象。
- 更新家庭成员信息：在 `data.members` 数组中编辑对应字段。
- 调整家务与食谱：分别更新 `data.tasks` 与 `data.recipes` 数组。

修改后刷新页面即可看到最新内容。
